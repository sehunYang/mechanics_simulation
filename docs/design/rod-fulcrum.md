# 돌림힘 요소 — 막대 · 받침 (설계)

돌림힘과 평형(지레·두 받침 위 막대·실에 매단 막대)을 다루려고 **막대**와 **받침 쐐기** 두 요소를 더했다.
이 문서는 그림 규격, 물리 모델, 편집 방식, 측정, 검증을 정리한 설계 기록이다. 코드 위치는
[ARCHITECTURE.md](../ARCHITECTURE.md) 의 "물리 엔진 요약 — 막대" 를 보라.

## 1. 요구와 결정

| 요구 | 결정 |
|---|---|
| 긴 막대 — 길이·무게 조절 | `RodBody`: 길이 1–30 m (0.5 m 단위), 질량, 초기 각도 θ₀ (−90°–90°, 반시계 +). 양 끝 핸들로 길이·각도를 함께 조절 |
| 받침 쐐기 — 놓은 자리에 고정 | `Fulcrum`: 실행 중에도 움직이지 않는 이등변삼각형 (역질량 0). 크기 0.5–4 칸 |
| 막대가 붙어 있으면 고정 여부를 체크박스로 | 꼭짓점이 막대 중심선 0.2 칸 안이면 "붙어 있음" (`fulcrumRodContact`). 그때만 속성 패널에 **막대를 받침에 고정 (회전축)** 체크박스. 켜면 핀, 끄면 받치기만 |
| 기존 요소와 조화 | 실은 막대 위 0.5 m 마다 (바닥면 앵커와 같은 `p1`·`s<d>`·`p2` 이름 + 가운데 `c`). 막대 ↔ 네모·원·고정점·다른 막대 실 지원. 받침 빗변은 네모·원에게 단단한 면 |
| 수능형 그림 규격 그대로 | 아래 §2. 화면과 📷 촬영(SVG)이 같은 그림 조각 목록을 그린다 |

계획 단계에서 정한 기본값 (사용자 확인: "모두 추천대로")
1. **막대 위에 물체 올리기**는 이번 범위에서 뺐다 — 실로 매다는 방식으로 대부분의 돌림힘 문항이 된다.
2. 받치기만 하는 받침의 접점 마찰 기본값 μs = 0.5, μk = 0.4 (마찰이 없으면 기운 막대가 바로 미끄러진다).
3. 막대 두께는 고정 0.25 칸 — 물리는 얇은 막대, 두께는 그림용.
4. 받침을 거꾸로 달아 천장 회전축으로 쓰는 것은 뺐다.

## 2. 수능 작도 규격

[suneung-drawing-convention.md](suneung-drawing-convention.md) 의 관례를 그대로 넓혔다.

| 대상 | 그림 | 근거가 되는 기존 관례 |
|---|---|---|
| 막대 | 가는 검정 테두리(`SN.lwGeom`) + 연회색 채움(`SN.bodyFill`) 의 회전된 긴 직사각형 | 물체(사각) 규격 |
| 막대 질량 | 막대가 얇아 안에 못 쓰므로 **밖(위쪽)** 에 이탤릭 `2 kg` | "글자가 넘치면 물체 밖으로" |
| 눈금 | 막대를 n 등분하는 짧은 가로선 (`SN.lwThin`) | 보조선 굵기 |
| 받침 | 이등변삼각형, 물체와 같은 테두리·채움. 밑변은 바닥선 위 | 물체 규격 |
| 고정 핀 | 꼭짓점에 흰 원 + 검정 축점 — 막대 **위**에 그린다 | 도르래 축핀 (흰 원 + 검정 점) |
| 받치기만 | 핀 없이 꼭짓점이 막대에 닿기만 | — |
| 치수선 | 막대 위쪽에 끝·받침·실 매단 점 사이를 양끝 화살표(`svgDimension`) + 점선 보조선. 라벨 `1.5 m` 또는 가장 짧은 구간의 정수배 `L · 3L · 4L` | 규격 문서 §3 이 미뤄 둔 "치수선" |

그리는 순서: 힘 구간 · **받침** → 바닥면 → 실 → 물체 · **막대** → **고정 핀**. 받침 꼭짓점은 막대 중심선까지
올라와 막대 채움에 가려지므로, 기울어도 꼭짓점과 막대 사이에 틈이 보이지 않는다.

`rodPictureParts` / `fulcrumPictureParts` / `fulcrumPinParts` (elements.js) 가 `{ shapes, labels }` 목록을 만들고,
화면은 `drawPictureParts`, 촬영은 `_svgParts` (capture.js) 가 같은 목록을 찍는다 — 보이는 그림 = 내보낸 벡터.

## 3. 물리 모델

**얇은 막대 이상화.** 질량중심은 가운데, I = ML²/12. 물리에서 막대는 두께 없는 **중심선**이다. 받침 꼭짓점과
실 앵커가 모두 중심선에 있으므로 질량중심 위에 받친 막대는 중립 평형이다 (교과서의 지레). 두께가 있는 판처럼
"아랫면"으로 받치면 질량중심이 받침보다 두께/2 높아 불안정 평형이 되어, 균형 잡힌 지레가 저절로 넘어간다.
바닥 충돌만은 보이는 네 모서리로 한다 (바닥에 누운 막대의 높이 = 바닥 + 두께/2).

**순서.** 한 서브스텝: 힘 → (모든 물체 속도 갱신 → **막대 제약 속도 단계** → 위치 갱신) → 네모·원 충돌 →
**막대 위치 보정** → 실 제약(막대에 걸리지 않은 실) → 에너지 보정.

**속도 단계 — 반복 순차 임펄스 (30회).** 한 행 = 물체별 (작용점 r, 방향 d). 유효 역질량 Σ(1/m + (r×d)²/I).
누적 임펄스를 클램프한다.

| 제약 | 행 | 범위 |
|---|---|---|
| 핀 (고정 받침) | x, y 두 행 | 양방향 |
| 받침 접촉 | 법선 (막대 법선, 위쪽) + 마찰 (막대 방향) | λn ≥ 0, \|λt\| ≤ μλn (접점이 이미 미끄러지면 μk) |
| 바닥면 ↔ 막대 모서리 | 법선 + 마찰 (마찰 바닥만) | 0.5 m/s 보다 빠른 충돌만 반발 e |
| 막대에 건 실 | 양 끝을 서로 당기는 방향 (팽팽할 때만) | λ ≥ 0 |

위치를 옮기기 **전에** 속도를 맞추므로 정지 마찰로 멈춘 막대가 서브스텝마다 v·dt 씩 기어가지 않는다
(네모의 바닥 충돌은 위치 뒤에 풀어서 같은 문제를 변위를 되돌려 막는다).

**위치 보정.** 핀은 2×2 를 바로 푼다 (K = I/M + r⊥r⊥ᵀ/I). 침투·실 늘어남은 같은 행 구조로 위치·각도만 옮긴다.

**에너지 보정.** 반음적 오일러 + 위치 보정은 진자처럼 도는 막대에서 10 초에 약 5 % 에너지를 흘렸다.
기존 실 성분 보정과 같은 원리로, 중력·핀·팽팽한 실**만** 받는 막대 계(막대 + 막대에 건 실로 이어진 네모·원,
다른 실·용수철이 없는 닫힌 계)는 서브스텝 전후 에너지 차를 속도 균일 배율로 되돌린다. 핀과 팽팽한 실의
속도 조건 J·v = 0 은 배율에 불변이다. 받침·바닥 접촉, 힘 구간, 느슨한 실이 끼면 보정하지 않는다. → 0.1 %.

**측정.** 속도 단계에서 각 행이 막대에 준 임펄스를 스텝 동안 모아 Δt 로 나눠 힘으로 기록한다
(`rod._fbd.forces` = 종류·라벨·성분·작용점). 같은 종류가 여럿이면 막대 왼쪽부터 T1, T2 … .
받침은 `fulcrum._force`, 막대에 건 실은 `rope._tension`. 네모·원처럼 잔차를 거꾸로 풀지 않는 이유:
미지수(받침 2축 + 장력 여러 개)가 식(Fx, Fy, τ)보다 많을 수 있다.

## 4. 편집

| 동작 | 결과 |
|---|---|
| 팔레트 → 막대 | 화면 가운데, 중심선이 격자선 위 |
| 막대 끌기 | 수평이면 왼쪽 끝, 기울었으면 중심을 반칸 격자에. 받침 꼭짓점이 중심선 0.5 칸 안이면 법선 방향으로 붙인다 |
| 막대 끝 핸들 | 드래그 시작 때 반대 끝을 고정. 길이 0.5 m, 각도 5° 단위. ±90° 를 넘어가면 p1·p2 를 맞바꿔 각도를 [−90°, 90°] 로 |
| 받침 끌기 | 반칸 격자. 밑변 가운데가 거의 수평인 직선 바닥면 0.6 칸 안이면 얹고, 아니면 꼭짓점을 막대 중심선에 (세로로만) |
| 패널: 길이·각도 변경 | 받침에 얹혀 있으면 그 접점을 축으로 바꾼다 (받침에서 떨어지지 않게) |
| 편집 경고 | `막대가 받침에도 실에도 걸려 있지 않습니다` · `막대에 이은 실은 고정점·물체·막대에만 걸 수 있습니다` |

받침의 "붙어 있는 막대"(`fulcrumRodContact`)는 저장하지 않고 매번 기하로 다시 구한다. 그래서 공유 링크·실행취소로
id 가 새로 발급돼도 다시 맞는다. 저장되는 것은 `pinned` 하나다.

## 5. 측정값 · 오버레이 · 콘텐츠

- 막대 패널: θ · ω · α · I · 운동에너지(병진 + 회전) · 받침 반작용 · 장력 T1, T2 · **힘마다 받침 기준 τ** ·
  **Στ (회전 평형 배지)** · 알짜힘 (힘 평형 배지). 편집 중: 받침 기준 무게의 돌림힘.
- 받침 패널: 고정이면 R (Rx, Ry), 받치기만 하면 N · f.
- 오버레이: 막대의 힘은 **작용점**에. 받침 아래에 Στ. 막대를 선택하면 받침에서 각 작용선까지의 팔(수선)과 길이.
- 그래프 θ–t (막대가 있을 때만 탭이 보인다), CSV 에 θ·ω 열.
- 헤드리스 측정 `theta · omega · alpha · tau · T1 · T2` (막대), `N · R · Ry · f` (받침). 스윕 대상·측정 대상에 막대·받침.
- 갤러리 3: 지레의 평형 · 두 받침 위의 막대 · 실에 매단 막대. POE 분류 **돌림힘·평형** 6문항, 해설 3, 탐구 1.

## 7. 2단계 (2026-10-01, 같은 날 이어서)

1단계에서 미뤘던 항목을 모두 넣었다. 검증은 `test/spec18.js` (10 시나리오).

|---|---|---|

| 용수철 | 세로 용수철 끝이 수평 막대 아랫면·윗면에 닿으면 체결. 축이 닿은 점(실행 시작 때 d 고정)에 힘 | kx = Mg/2 로 수평 유지 |

## 8. 3단계 (2026-10-01, 이어서)

검증은 `test/spec19.js` (5 시나리오).

| 항목 | 구현 | 검증 |

| 움직도르래 · 직렬 도르래 | **막대 실 네트워크** `rodRopeNetwork` — 막대와 실로 이어진 성분 전체. 림 실이 둘인 도르래마다 실을 이어 "길이 합 일정" 한 줄로 묶고, 줄마다 행 하나 (`_netRow`). 같은 물체의 항을 합치므로 움직도르래는 두 구간의 장력을 함께 받는다(2T). 막대 계의 움직도르래는 0.05 kg 의 가벼운 마디로 integrate 가 함께 적분 (장력 오차 ≈ m·a). 기존 1단계의 고정 도르래 전용 경로는 이 일반 경로로 바뀌었다 | 움직도르래 지레 T = W/2 · R = ΣW, 무거우면 하중·도르래가 같이 내려감 / 직렬 도르래 세 구간 장력 균일 |

## 9. 하지 않는 것 (이유)

- **림 실이 셋 이상인 도르래** — 한 실이 도르래를 지나는 모양(두 가닥)이 아니면 어느 가닥끼리 이어지는지 정할 수 없다.
  편집 경고(`막대 쪽 도르래에 실이 세 가닥 이상 걸려 있습니다`)로 안내한다. 하중은 도르래 중심에 걸면 된다.
- **막대 위 상자가 모서리로 넘어지기** — 네모 회전 물리(관성모멘트, 모서리 접촉)가 엔진 전체에 없다. 막대만의 일이 아니라
  네모 물체 전반을 강체로 바꾸는 큰 작업이다.
